# 마이핏로그
재호의 개인용 오프라인 Android 운동 기록 앱. Kotlin + Jetpack Compose(Material 3), Android 8 이상. 설정 화면은 Java로 유지합니다. 서버·로그인·사진·외부 AI API 없음.

## 사용
1. **내 운동 → 운동 추가**에서 PT에서 배운 정확한 운동 이름, 장비, 자세 메모와 목표 무게·횟수·세트를 등록합니다. 덤벨 무게는 한 개 기준입니다.
2. 집의 3kg 덤벨 두 개로 혼자 할 수 있는 운동에 체크합니다.
3. **오늘 → 오늘 루틴 구성** 또는 **루틴 편집**에서 장소와 운동을 고른 뒤 적용합니다. 최근 기록이 오래된 운동부터 최대 3개를 기본 선택하는 단순 규칙이며, 직접 선택을 바꿀 수 있습니다. 근육별 회복 상태를 판단하는 처방 기능이 아닙니다.
4. **운동 시작 / 이어하기**에서 실제 무게·횟수를 입력하고 하단의 **세트 완료**를 누릅니다. 자세·컨디션 메모를 펼쳐 볼 수 있고, 방금 기록한 세트는 실행 취소할 수 있습니다. 같은 운동·장소의 이전 날짜 기록을 표시합니다.
5. **PT 운동 기록하기**는 오늘 화면 또는 PT 탭에서 열 수 있습니다. 운동 시작 없이 운동별 무게·횟수(모르면 공란)와 세트 수를 입력해 한 번에 기록합니다. PT는 일반 루틴 구성에서 제외하고 기록은 기존 **기록** 탭에 저장합니다. **오늘 기록한 PT 운동 → 전체 삭제**에서 해당 날짜·운동의 모든 PT 세트를 확인 후 일괄 삭제할 수 있습니다. 같은 날 같은 운동을 여러 번 등록했다면 모두 삭제되며 다른 운동과 다른 날짜의 기록은 유지됩니다.
6. **예약**에서 PT 날짜·시간과 알림 시점을 등록합니다. 반복 예약은 없습니다. 수정·삭제 및 재부팅 후 알림 복구를 지원합니다. Android 알림 권한을 허용해야 합니다. 기기 정책 때문에 알림이 늦게 표시될 수 있습니다. 앱을 강제 종료한 뒤에는 다시 실행해야 알람이 복구됩니다.
7. **설정**에서 주간 목표(1~7일)를 바꾸고 JSON 백업을 저장하거나 복원합니다. 복원은 현재 데이터를 교체합니다. 앱 삭제 전 백업하세요.

## APK 받기
main 브랜치의 GitHub **Actions → Android APK → 성공한 실행 → Artifacts → my-fit-log-signed-apk**에서 ZIP을 내려받고 압축을 풀어 `app-release.apk`를 설치합니다. GitHub 로그인이 필요할 수 있으며 CI에 배포 서명 설정이 필요합니다. 로컬 테스트 APK는 빌드 후 `app/build/outputs/apk/debug/app-debug.apk`에 생성됩니다.

## 빌드
Android SDK 35, JDK 17 또는 21에서 프로젝트 루트를 엽니다. Gradle 8.9 wrapper를 포함합니다.
```sh
./gradlew testDebugUnitTest assembleDebug lintDebug
```
에뮬레이터나 테스트 기기를 연결한 뒤 UI 흐름 검증:
```sh
./gradlew connectedDebugAndroidTest
```
UI 테스트는 테스트 기기의 이 앱 데이터를 예시 데이터로 교체하므로 개인 기록이 없는 테스트 기기에서 실행하세요.

## UI 개편 현황
- 오늘·운동 진행·내 운동·기록·PT 화면은 Kotlin + Compose + Material 3로 구현했습니다. 시스템 다크 모드를 지원합니다.
- 내 운동에서 이름·장비·메모 검색, 집 운동 필터, 운동 선택 또는 직접 등록, 목표·자세 메모 수정, 삭제를 지원합니다.
- 목표 수정은 새로 구성하는 루틴부터 반영하며, 운동 삭제 후에도 수행 기록은 유지합니다.
- 기록 화면은 날짜·운동·장소별 요약과 펼쳐보는 세트 상세, 이번 주 필터, 세트 삭제를 지원합니다. 삭제한 세트는 오늘 진행과 주간 달성 일수에도 반영됩니다.
- PT 화면은 다음 예약 강조, 지난 일정 접기, 날짜·시간·메모 수정과 삭제를 지원합니다. 지난 예약에서 다시 예약하면 원래 일정은 유지합니다.
- 알림 권한 상태와 이미 지난 알림 시각을 표시합니다. 예약 수정·삭제 시 알람과 표시된 알림을 정리하고, 앱 실행·재부팅 후 미래 알람을 복구합니다.
- 설정은 기존 Java 화면으로 연결합니다.
- 기존 `fit` / `db` 저장 키, JSON 백업 version 1, applicationId를 유지합니다. 새 세트의 선택적 `entryId`는 실행 취소 대상을 구분합니다.
- [시안과 구현 계획](docs/design/README.md), [HTML 시안](docs/design/preview.html)을 참고하세요.

## 범위와 확인사항
- 1986년생, PT 입문, 상체 근력·자세 개선 프로필, 집 장비 3kg 두 개를 기본 표시합니다.
- 주간 목표 달성은 세트 기록이 있는 서로 다른 날짜 수로 계산합니다(월요일 시작).
- 운동별 목표는 직접 설정하며 자동 증량하지 않습니다.
- 첫 버전은 오늘 계획만 지원합니다. 미래 운동 일정, 차트, 휴식 타이머, 자동 증량, 장비 프로필 편집은 추후 기능입니다.
- 실제 기기에서 예약 알림/재부팅, 백업 복원, 뒤로 가기와 입력 동작 확인이 필요합니다.
