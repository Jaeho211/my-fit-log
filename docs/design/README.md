# UI 개편 초안

`preview.html`을 브라우저에서 열면 오늘·운동 진행 화면을 나란히 확인할 수 있습니다. 좁은 화면에서는 세로로 배치됩니다. 외부 의존성이나 네트워크 요청이 없습니다.

## 디자인 결정안

- 밝은 중립색 배경, 진한 글자, 청록 포인트. 주요 행동과 완료 상태에 강조색 사용.
- 오늘 화면은 루틴과 시작/이어하기를 우선하고 주간 목표·PT 일정은 아래에 배치.
- 장소 변경은 루틴 편집 안으로 이동하고 적용 버튼으로 확정.
- 운동 중에는 간결한 세트 표와 직접 편집 가능한 무게·횟수 입력 사용.
- 기록 버튼은 화면 하단에 고정. 세트 완료 직후 실행 취소 제공.
- 자세·컨디션 메모는 펼쳐서 확인. 이전 수행 기록과 현재 입력 구분.

## 시안 범위

첫 사용·루틴 준비·하루 완료 상태 전환, 루틴 장소 변경, 3세트 입력과 실행 취소를 체험할 수 있습니다. 데이터는 임시 메모리만 사용합니다. 설정·기록·운동 목록·PT·다음 운동 화면은 후속 설계 범위입니다. 표시한 운동·일정·수치는 예시입니다. 실제 Android 실행 화면을 캡처하거나 비교한 결과는 아닙니다.

## 구현 순서

1. 실제 기기에서 기존 앱의 빈 상태·운동 진행·완료 상태와 키보드 동작 확인.
2. 이 시안으로 레이아웃·색상·기록 동선 확정.
3. Gradle wrapper 추가와 현재 빌드 확인. Kotlin/Compose 도입 시 호환 버전 확정.
4. 기존 JSON 스키마·SharedPreferences 키·백업 형식을 유지하며 Repository와 모델 분리.
5. Compose Material 3 테마, 화면별 ViewModel과 탐색 구조 구성.
6. 오늘·운동 진행부터 전환한 뒤 내 운동·기록·PT·설정 전환.
7. 기존 설치본 업데이트, 데이터·백업 호환, 알림과 재부팅 복구 검증.

UI 전환과 Room 등 저장소 교체는 별도 작업으로 진행합니다. 기존 applicationId와 배포 서명을 유지합니다.

## 완료 기준

- 오늘 화면에서 한 번 눌러 운동 시작 또는 이어하기.
- 일반적인 휴대폰 크기에서 주요 세트 입력과 기록 버튼이 함께 보임.
- 큰 글씨·작은 화면·키보드 표시 중에도 입력과 완료 동작에 접근 가능.
- 세트 완료·취소 시 입력 상태와 기록 수가 일치하고 중복 기록을 방지.
- 기존 기록, 운동 목표, 예약, JSON 백업 호환 유지.

## 1차 구현 결과

- 앱 진입점과 오늘·운동 진행 화면을 Kotlin + Compose Material 3로 전환했습니다.
- 화면 파일, ViewModel, JSON 데이터 처리와 Android 저장소를 분리했습니다.
- 입력을 세트 목록 위에 배치해 세트가 많을 때도 입력 접근을 우선합니다.
- 기존 운동 등록·기록 조회·PT·설정은 `LegacyActivity`에 유지하고 새 홈에 연결했습니다.
- 기존 저장 키와 백업 version 1을 유지합니다. 새 로그의 선택적 `entryId`는 정확한 실행 취소에 사용합니다.
- Gradle wrapper와 체크섬을 추가하고 CI에 데이터 테스트를 연결했습니다.

실제 Android 16 에뮬레이터 캡처입니다. 개인 데이터 대신 예시 운동과 일정을 사용했습니다.

### 검증

- 데이터 테스트 7개: version 1 호환·알 수 없는 필드 보존, 중복·날짜 변경 방지, 정확한 실행 취소, 장소별 이전 기록, 집 목표, 주간 집계, 입력 범위.
- Android 16 UI 테스트 4개: 입력값 저장·취소, 화면 재생성 후 입력 유지, 기존 관리 화면 왕복, 루틴 편집 취소.
- 기존 소스의 APK를 설치하고 version 1 예시 데이터를 넣은 뒤 새 APK로 업데이트: 운동·계획·기록·예약·주간 목표 JSON 동일성 확인.
- 320 × 640 dp 화면, 글자 배율 1.5에서 입력 접근과 완료 버튼 표시 확인. 키보드를 열어도 입력칸과 완료 버튼에 접근 가능.
- 라이트·다크 모드 화면 확인. lint 오류 0개. 라이브러리 업데이트 제안과 기존 Java·리소스 관련 경고는 남아 있습니다.

실제 휴대폰의 알림·절전·재부팅, 파일 선택기를 통한 백업 저장·복원은 추가 확인이 필요합니다. 배포 서명 APK는 생성하지 않았습니다.
